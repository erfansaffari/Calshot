# Calshot voice server

Stateless Vercel functions (`calshot-voice`, https://calshot-voice.vercel.app) for the three halves of voice (listening, thinking and speaking), which Calshot provides for every verified account. The Mac never holds a Google or OpenAI key.

- `POST /api/voice/ears-token` `{vocabulary?: string[]}` → `{token, url, model, expiresIn}`: a one-use Gemini Live token, valid to start a session for 60 s and for 11 minutes after, with the whole setup locked (`gemini-3.5-transcribe-live`, text-only responses, manual activity detection, the caller's calendar words as `customVocabulary`).
- `POST /api/voice/brain` `{input, tools, cache_key}` → OpenAI's Responses event stream, relayed unchanged. The server fixes `gpt-6.1-sol`, `service_tier: "ultrafast"`, low reasoning effort and verbosity, `max_output_tokens: 2000`, `store: false` and no parallel tool calls. It accepts only conversation items (developer, user and assistant messages, function calls and outputs, reasoning) and function tools, and sends `prompt_cache_key` from the session key and a one-way hash of the account as `safety_identifier`.
- `POST /api/voice/speak` `{text, voice}` → raw 24 kHz mono PCM16 (`audio/l16`), streamed from `gemini-3.8-flash-lite-tts` with `store: false`. One sentence of at most 600 characters; the voice must be one of the 30 prebuilt names. `{warm: true}` opens the instance's connections when voice starts and returns 204 without speaking or counting.

Every request carries the Calshot (Supabase) session. No token, audio or model output is returned until `public.consume_voice_allowance`, run with that session, has refused unverified or anonymous accounts and counted the account's UTC-day allowance (60 listening sessions, 40,000 spoken characters, 400 model requests; migrations `20261119090000_voice_allowance.sql` and `20261119120000_voice_brain_allowance.sql`). For speech and the brain, a session whose ES256 signature the server verified against the project's published keys starts the upstream call while the allowance is drawn; a refusal cancels it. A session it cannot check waits for the database. Responses carry `Server-Timing`. Errors never echo upstream details. No audio, text, vocabulary, conversation or calendar content is stored or logged.

Environment: `GEMINI_API_KEY` and `OPENAI_API_KEY` (sensitive, Production). Tests: `npm test` (fictional fixtures only). Typecheck: `npm run typecheck`. Deploy: `npx vercel@50.4.2 deploy --prod` from this folder (linked to `erfansaffaris-projects/calshot-voice`). Verified 2026-11-19: unsigned requests and invalid sessions return 401.
